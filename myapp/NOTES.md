# Meilleures extensions Visual Studi Code pour MERN

## 🔹 **Extensions Générales (Essentielles)**

1. **ESLint**  
   - Analyse et corrige votre code JavaScript/TypeScript en suivant les bonnes pratiques.  
   - *Indispensable pour React et Node.js*.

2. **Prettier**  
   - Formate automatiquement votre code (JS, JSX, CSS, JSON, etc.).  
   - *À configurer avec ESLint pour éviter les conflits*.

3. **GitLens**  
   - Superpuissance Git intégrée à VS Code (blame, historique, différences).  

4. **Live Server**  
   - Lance un serveur local avec rechargement automatique pour le frontend.  

5. **Path Intellisense**  
   - Auto-complétion intelligente pour les chemins de fichiers (`import`).  

6. **Bracket Pair Colorizer**  
   - Colorise les paires de parenthèses/accolades pour une meilleure lisibilité.  

7. **Error Lens**  
   - Affiche les erreurs ESLint/TypeScript directement dans le code.  

---

## 🔹 **React.js (Frontend)**

8. **Reactjs code snippets** (charalampos karypidis) 
9.    - Raccourcis pour les composants React (ex: `rfc` pour un *Functional Component*).  

10. **Simple React Snippets**  
   - Autres snippets utiles pour React (ex: `imr` pour `import React`).  

11. **Auto Rename Tag**  
    - Renomme automatiquement les balises HTML/JSX jumelles.  

12. **Tailwind CSS IntelliSense** (si vous utilisez Tailwind)  
    - Auto-complétion pour les classes Tailwind.  

---

## 🔹 **Node.js & Express (Backend)**

12. **REST Client**  
    - Permet de tester les API REST directement depuis VS Code (alternative à Postman).  

13. **Thunder Client** (alternative à REST Client)  
    - Client HTTP léger pour tester les endpoints.  

14. **MongoDB for VS Code**  
    - Interface pour interagir avec MongoDB depuis VS Code.  

15. **DotENV**  
    - Support amélioré pour les fichiers `.env` (coloration syntaxique).  

---

## 🔹 **Débogage & Performances**

16. **Debugger for Chrome / Firefox**  
    - Débogage des applications React directement depuis VS Code.  

17. **Node Debug**  
    - Débogage des scripts Node.js.  

18. **Import Cost**  
    - Affiche la taille des paquets importés (utile pour optimiser les bundles).  

---

## 🔹 **Bonus (UI & Productivité)**

19. **Material Icon Theme**  
    - Icônes modernes pour une meilleure visibilité des fichiers.  

20. **Todo Tree**  
    - Affiche les commentaires `TODO`, `FIXME` dans l’explorateur.  

21. **Quokka.js**  
    - Exécution rapide de code JavaScript/TypeScript en temps réel.  

---

## 🚀 **Configuration Recommandée**  

- **ESLint + Prettier** : Configurer un formattage automatique à l’enregistrement (`"editor.formatOnSave": true`).  
- **Settings Sync** (optionnel) : Sauvegarde/restaure vos paramètres VS Code via GitHub.  

Avec ces extensions, vous gagnerez énormément de temps et de confort sur vos projets MERN ! 🎉
